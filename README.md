## Run it

```sh

```

Writes the image to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Node 22, stdlib only, no network. The image bytes are embedded in `main.ts`, so the output is byte-identical on every run.
